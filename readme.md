# 情绪小邮局 3.0：情绪信件的一天

一个基于 React + Vite 的儿童情绪教育交互原型。项目不包含后端，进度使用浏览器 `localStorage` 本地保存。

## 玩法流程

```txt
收信 → 分拣 → 派送 → 读信 → 回信 → 盖邮戳 → 收集邮票
```

孩子扮演情绪邮局的小邮递员，从今日邮袋中读取小动物寄来的情绪信，根据情绪线索进行分拣，再沿派送路线把信送到对应地点，完成互动任务并写出友好的情绪回信。

## 核心功能

- 今日邮袋：展示来自小动物的情绪信。
- 信件分拣：把信分到难过、生气、着急、害怕邮箱。
- 派送路线：将已分拣的信送到玩具屋、森林操场、排队小站、安静角落或 3D 探索区。
- 多样小游戏：卡牌组合、角色扮演对话、冷静进度条、情绪识别与安慰选择。
- 回信系统：帮助小动物生成友好的情绪回信。
- 盖邮戳与邮票册：完成任务后获得对应邮票。
- 学习报告：按表达需求、礼貌沟通、耐心等待、共情关心、情绪识别展示练习进度。
- Three.js 场景：包含 3D 友谊广场和 Kenney 模型资源。

## 运行方式

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
```

## 技术栈

- React
- Vite
- Three.js / @react-three/fiber / @react-three/drei
- CSS
- localStorage

## 目录说明

- `src/App.jsx`：主流程、信件数据、小游戏、邮票和报告。
- `src/App.css`：整体界面和邮局主题样式。
- `src/scenes/ThreeDFriendshipSquare.jsx`：3D 友谊广场。
- `public/models`：运行所需 3D 模型与贴图资源。
